# Module 3 - Express.js Answers

Each `Qn_*.js` file is a separate Express example. Run one at a time from this
folder after installing Express:

```powershell
npm install express
node Qn_7.js
```

Replace `Qn_7.js` with the question file you want to run. Visit
`http://localhost:3000` (or its route path); stop the server with Ctrl+C.
Express is not installed in this module folder, so run the install command
here before starting an example. The examples use in-memory data, which resets
when the server stops.
